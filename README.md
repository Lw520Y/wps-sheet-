# wps-sheets 批量修改 Sheet 名称-Clash

一个小工具：按照 Excel 里的映射表（原名称 → 新名称），批量重命名工作簿中的所有 sheet。配合 WPS 的 `SHEETSNAME` 函数，可以先把全部 sheet 名提取出来，在表格里填好新名称后一键批量改名。

## 使用准备：填写映射表

1. 打开要改名的 Excel 文件（`.xlsx` / `.xlsm`）。
2. 在名为 **Sheet1** 的工作表中填写映射（第 1 行留空作表头，数据从**第 2 行**开始）：

   | 列 | 内容 |
   | --- | --- |
   | A 列 | sheet 原名称 |
   | B 列 | sheet 新名称 |

3. A 列的名称可以用 WPS 函数自动生成：在 A2 输入 `=SHEETSNAME(,1,1)`，会自动向下填充列出所有 sheet 名称；B 列手填对应的新名称即可。
4. **填完后保存并关闭文件**（公式结果需要保存过才能被读取；文件被占用时无法写入）。

## 运行方式

仓库里已附带打包好的 **`批量修改sheet名称.exe`**（单文件版，无需安装 Python），三种方式任选其一：

- **双击 exe**：弹出文件选择窗口，选中 Excel 文件即可；
- **拖拽**：把 Excel 文件拖到 exe（或脚本）图标上；
- **命令行运行脚本**（适合有 Python 环境的用户）：

  ```bash
  python 批量修改sheet名称.py "文件.xlsx"
  ```

## 环境要求

- **exe 版**：无需任何依赖，Windows 下直接运行（单文件约 34MB，已内嵌 Python 运行时和依赖库）；
- **脚本版**：Python 3 + openpyxl（安装：`pip install openpyxl`，脚本检测到缺失会提示）。

## 重新打包

修改脚本后可用 PyInstaller 重新生成 exe：

```bash
pip install pyinstaller
pyinstaller --onefile 批量修改sheet名称.py
```

生成的 exe 在 `dist/` 目录下（需保留控制台窗口显示进度，不要加 `--noconsole` 参数）。

## 功能说明

- **自动备份**：保存前在原目录生成一份带时间戳的备份文件，改名失败或改错了可随时回退。
- **改名前校验**，有问题的行会跳过并列出原因，不会中断整个流程：
  - 新名称违反 Excel 规则（为空、超过 31 字符、含 `: \ / ? * [ ]`、以单引号开头/结尾）；
  - 原名称找不到对应的 sheet；
  - 新名称与现有其他 sheet 重名，或映射内部重复（sheet 名不区分大小写）。
- **支持链式改名**：如 A→B 且 B→C 这类换名场景会自动通过临时名过渡，不会中途撞名。
- 原名 = 新名的行自动忽略；A、B 列都为空的行自动跳过。
- 微信/QQ 接收的文件常带只读属性，保存前会自动去除。

## 配置项

需要调整时修改脚本顶部的常量：

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `MAPPING_SHEET` | `'Sheet1'` | 存放映射表的工作表名称 |
| `START_ROW` | `2` | 映射数据起始行 |

## 注意事项

- 运行前请先在 WPS/Excel 中**关闭**目标文件，否则保存会失败（此时原文件不受影响，关闭后重跑即可）。
- 若 A 列用的是 `SHEETSNAME` 等公式，需在 WPS 中保存过文件，公式才有缓存值可供读取。
- exe 未做数字签名，首次运行时 Windows SmartScreen 可能弹出「未知发布者」提示，选「仍要运行」即可；部分杀毒软件可能需要手动放行。
